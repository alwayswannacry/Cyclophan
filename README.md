# Cyclophan
Cyclophan - утилита, которая позволяет подделывать школьные пропуска, отправляя данные, заполненные в пункте 1, в локальную LLM на вашем компьютере, в уже подготовленный промпт для заполнения бланка введенными данными. Утилита позволит вам безнаказанно скипать шкилу:)
Cyclophan is a utility that lets you forge school passes - it takes the information entered in the first step and feeds it into a preconfigured prompt for a local LLM running on your computer, which then fills out the form with the provided details. This tool allows you to skip school with impunity :)
